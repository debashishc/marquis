# MARQUIS: Three-Stage Pipeline for Video Retrieval-Augmented Generation

MARQUIS is a three-stage pipeline for video retrieval-augmented article generation. It decomposes complex queries, retrieves and reranks relevant videos, extracts calibrated evidence, and generates cited articles from that evidence.

The system includes retrieval, evidence extraction, calibration, QA-based generation, GINGER-based generation, and an optional Recursive Language Model controller.
